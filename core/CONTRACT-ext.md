## 基本方針
- core は計測しない。値の取得・権限・端末時刻は Watch/iPhone 側（蝦名さん）
- **入力なしなら今の core と同じ結果**になる（後方互換）。追加は `step(state, config, input?)` の第3引数で受ける
- core の時計は `tick` だけ。センサーを受け取った時刻で core の時間を進めない。端末時刻 → 走行経過秒への変換は外側で行い、どの tick に入力を適用したかを記録する（同じ入力の列で再現できるように）

## 入力（案）
| 項目 | 単位・意味 | 注意 |
|---|---|---|
| `measured.speedMps` | 実測速度 m/s | 歩幅×BPM からの推定速度とは別に持つ。GPS 速度と同一視しない |
| `measured.cadenceSpm` | 実測ケイデンス 歩/分（両足の合計） | 目標値と区別。片足/両足の数え方を揃える |
| `measured.heartRateBpm` | 心拍数 拍/分 | ケイデンスと別項目。**心拍の値を目標ケイデンスに入れない** |
| 各値の付帯情報 | `{ value, measuredAtS, source, quality }` | 欠損は `value: null` と理由。古さは `measuredAtS` で判定 |
| `userRequest` | `{ id, action: 'normal'｜'slow'｜'stop'｜'resume' }` | 明示操作。停止は**信号待ちと別の状態** |
| `effortConstraint` | `{ active, noAcceleration, maxCadenceSpm, validUntilS, source }` | 加速禁止や上限。**既定は無効**。閾値の決まっていない心拍から自動生成しない |

表示用ペース `paceSecPerKm` = 1000 / speedMps（speedMps > 0 のときだけ。停止中は `null` として表示し、0で割らない）。

## 出力（案）
| 項目 | 意味 |
|---|---|
| `targetCadenceSpm` | 目標歩/分（今の `targetBpm`） |
| `reason` | `signal`（信号合わせ）／`user`（ユーザー操作）／`effort`（減速制約）／`dataUnavailable`（欠測）／`none` |
| `guidanceStatus` | `active`（信号誘導中）／`suspended`（制約と衝突して打ち切り）／`off` |
| `waitingReason` | `signal`（信号待ち）／`user`（ユーザーの停止） |

## 優先順位（Y12）
1. **ユーザーの停止・減速要求**を最優先する
   - `stop` は状態として保持し、**青信号で自動解除しない**。解除は `resume` の明示操作だけ
   - 停止は通知・目標に反映するが、実際の人の速度を制御できるわけではない
   - 通常BPM−20 の下限で停止・減速を妨げない
2. **有効な減速制約**を、信号の候補選択より先に当てはめる
   - 候補を「上限以下」「加速しない」に絞ってから青に間に合うか調べる。間に合わなければ `stopRecommended`
   - 制約の上限が 通常BPM−20 を下回るなど信号誘導と両立しないときは、`guidanceStatus: 'suspended'` にして信号誘導を打ち切る。**勝手に通常BPMへ戻さない**
3. 残った候補の中で、**信号に合わせるテンポ**を選ぶ（今の chooseTarget）

信号向けの±20BPM・4秒/2BPM は**心拍上の安全性を示すものではない**。ユーザーの停止・減速と新しい制約は即時に反映し、段階調整の例外として記録する。

## 欠測・古い値（Y11）
- 実測モードで心拍・速度が欠けていても「問題なし」とは扱わない。`reason: 'dataUnavailable'` を出し、**信号向けの加速提案を止める**
- 最後の値を使ってよいのは `maxAgeS` 以内だけ（値は要合意）
- 実測中に**黙って模擬値へ切り替えない**。シミュレーションモードの既定値とは別に管理する
- 平滑化の方式・窓、外れ値の扱い、閾値の継続判定と解除条件は、決めた値を記録する（閾値付近で指示が往復しないこと）

## 心拍からの制約（Y15・検証待ち）
- 閾値・持続時間・解除条件・個人設定は**未定**。医学的な閾値や自動停止の保証は定義しない
- デモで架空の閾値を使う場合は「模擬ルール」と表示する
